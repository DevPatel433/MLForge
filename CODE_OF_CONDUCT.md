# Code of Conduct

We follow the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

**Our standard.** Be respectful, welcoming and constructive. Critique code and ideas, not people. Assume good faith. Help newcomers - this is a learning project.

**Unacceptable behaviour** includes harassment, discrimination, personal attacks, trolling, publishing others' private information, and any conduct that would be inappropriate in a professional setting.

**Enforcement.** Maintainers may edit, reject or remove contributions and may temporarily or permanently ban contributors who violate this code. Report problems to the maintainers via a private GitHub security advisory or the contact listed on the repository profile. Reports are handled confidentially.
